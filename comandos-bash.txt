pwd -> mostra exatamente em qual diretorio você está 
cd -> acessa um diretório
ls -> lista os arquivos do diretório
ls -a -> lista os arquivos exibindo também arquivos ocultos
cat -> mostra o conteúdo do arquivo
mkdir -> cria um diretório
rm -rf -> remove de forma recurssiva e forçada o diretório
touch -> cria ou atualiza um arquivo.
